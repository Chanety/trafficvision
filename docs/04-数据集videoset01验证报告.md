## 三、失误成因总结

| 成因 | 证据 | 性质 |
|---|---|---|
| 目标像素位移大（近处/快速） | 快慢目标误差差 8 倍 | 物理必然，需按位移归一化报告 |
| 密集场景轨迹碎片化 | 450 帧出现 143 条轨迹 | **可修正**，已用 TrackTrack 解决大半 |
| 手持相机抖动 | 140539 帧间位移 0.78 px，误差最大 | **可避免**（固定机位） |
| 帧率不统一 / VFR | 10 种帧率、5 段 VFR | 本批影响小，但换设备即成隐患，已做防护 |
| 类别运动非线性 | 摩托车误差最高（94.9 px） | 模型固有，需专用轨迹模型 |
| 时长/分辨率规格不一 | 4 段超 30 秒、3 种分辨率、含竖屏 | 已做自动截取与自适应处理 |

## 四、已实施的修正

1. **真实时间戳计时**：改用容器时间戳而非"帧号÷帧率"，兼容可变帧率视频
2. **默认跟踪器换成 TrackTrack**：碎片化下降 70~81%，覆盖率提升 11~17 个百分点
3. **逐视频自适应帧率**：不再假设统一帧率，每段独立读取
4. **超长自动截取**：超过 30 秒自动取前 30 秒并提示
5. **维度判定有效性门控**：贴边样本剔除、地平线跨轨迹联合估计、不可用时自动回退
6. **预判有效性门槛**：轨迹过短或近乎静止的目标不输出预判，避免误导

## 五、待解决与建议

1. **缺少标注真值**：当前评测用"检测器自己未来的框"当真值，
   无法区分"检测抖动"与"预判偏差"。需要人工标注一批真值才能给出可信精度
2. **建议固定机位复拍 140539 场景**：可直接验证抖动对该场景误差的贡献
3. **按位移归一化报告精度**：建议产品指标改为"相对位移误差"，而非单纯像素误差
4. **摩托车/自行车需单独建模**：这两类运动非线性最强，匀速模型天然吃亏

## 七、更正与干净基线（排除手持抖动片段）

按要求排除唯一存在手持抖动的 `VID_20261003_140539`，用当前配置（ByteTrack）在 14 段上重建基线。

### 7.1 更正：TrackTrack 的结论是错的

第二节曾根据"可预判比例"判定 TrackTrack 更优，这是**分母效应造成的误判**。
按绝对数量重新对齐后（14 段平均）：

| 指标 | ByteTrack | TrackTrack | 变化 |
|---|---|---|---|
| 平均目标数/帧 | 8.15 | 3.95 | **−51.5%** |
| 平均可预判目标数/帧 | 5.05 | 2.80 | **−44.6%** |
| 平均轨迹条数 | 65.4 | 13.9 | −78.7% |
| 1秒平均误差（逐段平均） | ≈58.9 px | ≈81.5 px | 变差 |

原因：TrackTrack 的轨迹确认机制会把大量短轨迹直接不输出，分母变小使比例好看，
但**实际能给出预判的目标少了一半**；且保留下来的多为快速近距目标，误差反而更高。
默认跟踪器已**改回 ByteTrack**。

**教训**：评估跟踪质量不能只看比例指标，必须同时看绝对数量，否则很容易被分母效应误导。

### 7.2 干净基线（14 段，排除手持片段）

| 指标 | 数值 |
|---|---|
| 平均目标数/帧 | 8.15 |
| 平均可预判目标数/帧 | 5.05（覆盖率约 62%） |
| 平均轨迹条数/段（400 帧） | 65.4 |
| 1 秒误差 平均 / 中位 / P90 | 57.9 / 24.4 / 135.1 px |
| 相机稳定性 | 帧间位移 0.04~0.11 px（固定机位） |

### 7.3 相对误差：各分组高度一致

| 分组 | 相对误差中位 |
|---|---|
| 汽车 / 行人 / 摩托 / 公交 / 卡车 | 39% / 34% / 43% / 47% / 56% |
| 小目标 / 中 / 大目标 | 34.5% / 38% / 40.5% |
| 慢速 / 中速 / 快速 | 45% / 34% / 35% |

各组都在 35%~50% 区间，说明绝对误差的差异主要来自**位移量差异**，而不是模型对某类目标特别差。

### 7.4 位移增益标定：不是系统性偏差

对全部 13736 个样本拟合最优位移增益，并做留一视频交叉验证：

| 项目 | 结果 |
|---|---|
| 最优增益 g* | 0.896 |
| 修正后平均误差 | 57.9 → 56.5 px（**仅 2.5%**） |
| 留一验证平均改进 | 2.1%（13 段中 9 段变好，4 段变差） |

结论：**相对误差不是常量偏差造成的**，靠一个系数修不掉。误差主体是随机成分，
主要来自检测框抖动经速度估计放大，以及目标真实的非匀速运动。

### 7.5 修正后的优化优先级

| 优先级 | 方向 | 依据 | 预期 |
|---|---|---|---|
| 1 | 降低检测框抖动（微调检测模型） | 随机误差是主体，速度由框位置导出 | 直接改善速度估计与预判 |
| 2 | 提高轨迹存活率（跟踪参数调优） | 38% 目标因轨迹过短拿不到预判 | 覆盖率提升 |
| 3 | 按时间梯度分别调参 | 已实测短时需灵敏、长时需平滑 | 0.5~2 秒档小幅改善 |
| 4 | 摩托车/自行车单独处理 | 相对误差最高（43%/49%） | 局部改善，工作量中等 |
| 5 | 地面平面模型 | 当前几何下中性 | 换斜视机位后收益明显 |
