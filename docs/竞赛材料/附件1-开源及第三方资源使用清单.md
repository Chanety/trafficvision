## 六、团队自主开发部分（权利边界声明）

以下成果由团队独立设计、开发、调试与验证，团队依法主张相应权利，
计划以 AGPL-3.0 或更宽松许可开放（具体见开放计划）：

1. **预判软件主体 `trafficvision/`**：因果运动估计与四档梯度外推、静止状态机、
   串轨防护判据（`_TrackGuard`）、遮挡续推（`COAST_FRAMES`）、机动置信度判定、
   分梯度置信输出、画面渲染与中文标签。
2. **静态目标隐地图 `trafficvision/staticmap.py`**：整段视频跨帧一致性投票、
   遮挡判定、隐标记固化与漏检帧回补。
3. **上下文校验 `trafficvision/verify.py`**：基于零样本图文匹配的静态目标语义校验，
   含正/反例词表设计、多帧概率融合、与几何合理性规则的联合判决（keep / review / reject）。
4. **标注规则与工具**：载具优先标注规则、骑乘状态判定（`classify_riders`）、
   中文标注复核工具与自动标注质量清洗流程。
5. **数据集构建与评测体系**：按视频划分防泄漏的训练集构建、多版本公平对比、
   误差归因、跟踪器横评、系统性负结果实验（12 条技术路线的实测证伪）等 `bench/` 脚本。
6. **技术文档与报告**：方案、需求规格、验证报告、阶段报告与复现说明。

**第三方与自主部分的边界**：第三方资源提供的是通用能力（检测、跟踪、滤波、数值计算）；
本作品的核心价值——**短时预判链路、静态结构稳定性机制、上下文校验、
以及"哪些路线不成立"的系统性实验结论**——全部由团队自主完成。

## 七、合规结论与待办

**已完成核验**：全部 Python 依赖的许可证已逐一读取发行包元数据或包内 LICENSE 原文，
不存在"仅因公开可访问即视为可自由使用"的假设。

**需要完成的两项**：

1. **数据脱敏**：`videoset_01` / `videoset_02` 含公众场景，公开前须对人脸与车牌做脱敏处理。
2. **VisDrone 再分发边界**：确认原数据集条款；当前方案为不再分发原始图像，
   仅提供转换脚本，属保守处置。

**一项风险提示**：`clip` 发行包内 LICENSE 为 AGPL-3.0，而上游 OpenAI CLIP 为 MIT，
存在许可证歧义。本清单按最严许可处理；由于作品整体已选择 AGPL-3.0 开放，
该歧义不影响合规结论。若后续调整为闭源交付，须同步替换该依赖。
