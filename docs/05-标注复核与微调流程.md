# 标注复核与检测模型微调流程

日期：2026-10-03

## 一、为什么要做这一步

实测数据显示，预判误差的主要来源是**检测框抖动**（轨迹中心抖动占每帧位移的 26%），
以及密集场景中出现的**退化框**（把多个目标并成一个大框、框中心原地漂移）。
这两者同时污染速度与航向估计，使得转弯、掉头等机动行为根本无法被测量。

因此必须先有一个针对本机位、本视角的检测模型。本流程产出该模型所需的标注数据。

## 三、如何复核

双击运行 `tools\review_labels.bat`，或在项目目录执行：

```
trafficlab-3d\env\Scripts\python.exe tools\start_labelimg.py
```

启动器已自动完成这些设置：YOLO 格式、开启自动保存、图片目录、类别文件、标注保存目录。

### 常用快捷键

| 按键 | 作用 |
|---|---|
| `D` | 下一张（**自动保存当前修改**） |
| `A` | 上一张 |
| `W` | 开始画框 |
| `Del` | 删除选中的框 |
| 鼠标拖动框角 | 调整框大小 |
| 鼠标拖动框内 | 移动框 |
| `Ctrl` + 滚轮 | 缩放 |
| `Ctrl` + `F` | 适应窗口 |

### 改框大小（拖角缩放）

选中一个框后，框的四角与四边中点会出现 **8 个白色小方块**，
拖动它们即可改变框的大小（鼠标移到方块上会变成对应的缩放光标）。
拖动框内部是移动，拖动空白处是画新框。

> 这一步很重要：差异分析显示，此前人工复核几乎只做了"删框"和"改类别"，
> 匹配框的 IoU 中位数正好是 1.000，说明框的形状完全没被修正。
> 只有真正调整框的边界，微调后的模型才可能在定位上超过现有自动标注。

### 标注规范（重要，直接影响模型质量）

1. **贴合可见范围**：框要贴紧目标可见部分，不要包含多余背景
2. **遮挡时只框可见部分**：不要凭猜测补全被遮挡的区域
3. **出画目标框可见部分**：目标一半在画面外时，只框画面内的部分
4. **一律拆开**：一个框只能装一个目标。自动标注里把多个目标并成一个大框的，
   必须拆成多个；重叠的目标各自独立画框
5. **不要标注**：倒影、阴影、广告牌或屏幕里的车辆图像、小于约 10 像素的模糊目标
6. **先载具、后行人（重要性最高）**：先标载具，再标**不属于任何载具**的行人。
   骑车的人、驾驶位里的人、坐在三轮车上的人，**只标载具，不标 person**。
   理由是这类"人"的身份已经由载具表达，再单独标 person 会与载具框重叠，
   给模型自相矛盾的监督信号。

   > 实测：本数据集原有 2025 个行人框中有 **561 个**（28%）属于这种情况，
   > 已按此规则自动清理；清理前的原始标注备份在
   > `datasets/videoset_01_label/labels_backup_before_rules/`。
   > 工具里按 `R` 可以一键清理当前图中的重叠行人框；新画载具框时也会自动清理。
7. **类别判断**：摩托车含电动两轮车（含外卖车）；三轮载货归 motorcycle；
   小型厢式货车按 car 处理，明显大于轿车的载货车归 truck
8. **同一目标只画一次**，注意删除自动标注产生的重复框

### 复核重点（按优先级）

1. 删除误检（尤其是把背景、路面标线、广告牌当成目标的情况）
2. 检查骑车人：确认没有多余的 person 框与载具框重叠（按 `R` 一键清理当前图）
3. 拆开并框（自动标注最容易出错的地方）
4. 补上漏标的明显目标
5. 修正类别标错的（摩托车/自行车/汽车之间最容易混）

## 六、启动问题的排查

### 已修复的问题

labelImg 的 YOLO 读取器会到**标注目录**里去找 `classes.txt`，
只在数据集根目录放一份会导致启动时报 `FileNotFoundError` 并直接退出。
启动器现在会自动把 `classes.txt` 复制到 `labels/` 目录，问题已解决。

### 如果还是启动不了

改进后的启动器不会再一闪而过：

1. 窗口会**停住**并显示退出码（正常运行时关闭标注界面后按键即可）
2. 出错信息会写入 `tools/labelimg_error.log`
3. 把屏幕上的内容截图，或把该日志文件发我即可定位

### 使用提示

- 左上角工具栏如果显示的是 `PascalVOC`，点一下切换到 `YOLO`（启动器已默认 YOLO）
- 工具栏的"自动保存"如果没勾上，手动勾一下；或者每张改完按 `Ctrl+S`
- 关闭程序时会自动保存设置，下次打开保持同样的目录与格式
