# 标注复核与检测模型微调流程

日期：2026-10-03

## 一、为什么要做这一步

实测数据显示，预判误差的主要来源是**检测框抖动**（轨迹中心抖动占每帧位移的 26%），
以及密集场景中出现的**退化框**（把多个目标并成一个大框、框中心原地漂移）。
这两者同时污染速度与航向估计，使得转弯、掉头等机动行为根本无法被测量。

因此必须先有一个针对本机位、本视角的检测模型。本流程产出该模型所需的标注数据。

## 三、如何复核

双击运行 `tools\review_labels.bat`，或在项目目录执行：

```
trafficlab-3d\env\Scripts\python.exe tools\start_labelimg.py
```

启动器已自动完成这些设置：YOLO 格式、开启自动保存、图片目录、类别文件、标注保存目录。

### 常用快捷键

| 按键 | 作用 |
|---|---|
| `D` | 下一张（**自动保存当前修改**） |
| `A` | 上一张 |
| `W` | 开始画框 |
| `Del` | 删除选中的框 |
| 鼠标拖动框角 | 调整框大小 |
| 鼠标拖动框内 | 移动框 |
| `Ctrl` + 滚轮 | 缩放 |
| `Ctrl` + `F` | 适应窗口 |

### 标注规范（重要，直接影响模型质量）

1. **贴合可见范围**：框要贴紧目标可见部分，不要包含多余背景
2. **遮挡时只框可见部分**：不要凭猜测补全被遮挡的区域
3. **出画目标框可见部分**：目标一半在画面外时，只框画面内的部分
4. **一律拆开**：一个框只能装一个目标。自动标注里把多个目标并成一个大框的，
   必须拆成多个；重叠的目标各自独立画框
5. **不要标注**：倒影、阴影、广告牌或屏幕里的车辆图像、小于约 10 像素的模糊目标
6. **类别判断**：摩托车含电动两轮车（含外卖车）；三轮载货归 motorcycle；
   小型厢式货车按 car 处理，明显大于轿车的载货车归 truck
7. **同一目标只画一次**，注意删除自动标注产生的重复框

### 复核重点（按优先级）

1. 删除误检（尤其是把背景、路面标线、广告牌当成目标的情况）
2. 拆开并框（自动标注最容易出错的地方）
3. 补上漏标的明显目标
4. 修正类别标错的（摩托车/自行车/汽车之间最容易混）

## 四、复核完成后

告诉我一声，我会接着做：

1. 划分训练集与验证集（按视频划分，避免同一段视频的相似帧同时进训练和验证）
2. 微调检测模型（在现有开放词汇权重基础上继续训练）
3. 用**完全相同的评测口径**做改进前后对比：目标密度、轨迹抖动、1 秒预判误差、覆盖率
4. 如果效果达标，再在同一批标注上补充有向框，训练带车头朝向的模型
